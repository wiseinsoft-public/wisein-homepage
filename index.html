PAC

PAC — Process Automatic Channel

SAP ERP의 결산 프로세스를 자동화하는 솔루션입니다. 결산 준비 단계부터 사후 점검까지 전 과정을 모델링하고, 자동으로 실행하며, 결과를 실시간으로 모니터링합니다.

1 │ MODELING

프로세스 모델링

도식화 화면에서 프로세스를 손쉽게 배치합니다. 비즈니스 유형별 Standard Model과 조직 특화 Organization Modeling을 제공하여, 조직 변화와 규제 변경에도 업무 연속성을 유지합니다.

2 │ ONE CLICK

One Click Automation

모델링한 순서에 맞추어 One Click으로 자동 수행합니다. 원하는 구간만 선택해 실행할 수 있으며, 실시간 Refresh로 진행 상황이 즉시 반영됩니다.

3 │ AUTO TRIGGER

업무 간 자동 연계

타 모듈 · 타 시스템의 완료 상태를 자동으로 반영해 후행 프로세스를 실행하고, 결과를 Mail · To-Do · Messenger로 알립니다.

4 │ REWORK

재작업 자동 감지

완료된 프로세스에 연관 전표가 추가되면 자동 감지하여 상태를 'Rework Occurred'로 변경합니다. 조치 후 재실행(Re-run)이 가능합니다.

5 │ LOG

로그 감지 및 조회

Background · Foreground 수행 로그를 모두 감지하고 저장합니다. Log History로 전체 이력을, Document Summary로 전표 상세 내역을 확인할 수 있습니다.

6 │ ERROR HELP

오류 조치 지원

오류 발생 시 원인과 조치사항을 팝업으로 안내합니다. 오류 데이터가 쌓일수록 해결 능력이 고도화되어 조치 시간이 짧아집니다.

7 │ RELATIVE LINK

연관 프로그램 실행

Report · Transaction · Master · URL 등 프로세스와 연계된 프로그램을 수행 화면에서 바로 실행합니다.

8 │ MONITORING

실시간 모니터링

전 법인과 프로세스를 한 번에 파악하는 List View, 지역 · 국가 단위로 표현하는 Map View 두 가지 유형을 제공합니다.

CHECK

시나리오 기반 검증

점검 시나리오를 결산 전/후 원하는 단계에 등록하면 해당 시점에 자동으로 검증하고, 이상 데이터 발생 시 담당자에게 알립니다. 주요 고객사 사례 기반의 기본 시나리오를 제공합니다.

ALV MANAGER

결과 화면 자동 생성

ALV Layout 자동 생성 및 관리 기능을 제공합니다. 필드 속성과 Hot Spot 등 이벤트 연계를 설정만으로 구성할 수 있어 개발 기간이 단축됩니다.

PENDING

미처리 데이터 관리

전월 이전에 발생한 이상 데이터가 당월에도 남아 있으면 Pending으로 표시하고, 장기 미처리 리스트와 사유를 함께 관리합니다.

DEFINE

통제 항목 정의 · 배포

통제할 기표 유형과 마감 시간을 일정 ID로 정의하고, 결산 조직별 일정 계획을 배포 · 공지합니다. 마감 시간이 도래하면 회계 기표를 통제합니다.

LINKED

프로세스 연계 자동 마감

결산 마감 일정을 모델링과 연계하여 특정 시점에 자동 마감합니다. 마감 시간 전이라도 특정 프로세스가 완료되면 마감할 수 있습니다.

CONTROL

Time Zone · 권한 결재

법인별 시간대에 맞춘 통제를 지원하며, 일정 마감 내역 조회와 변경은 권한 점검 및 결재 연계를 통해 이루어집니다.

Closing Portal

  • 전용 Menu Tree 및 Favorite 제공
  • Closing Calendar로 결산 일정과 수행 상태 확인
  • Notification으로 결산 일정 · 담당자 공지
  • My To-Do에서 담당 프로세스 오류 발견 및 조치
  • 결산 수행 · 검증 · 일정 관리 · 권한 관리 통합

Real-time Monitoring

  • Process Type별 아이콘, Status별 색상으로 상태 표시
  • Graph 및 World Map 기반 모니터링
  • 전표 발생 현황 및 상세 로그 조회
  • Document Summary 조회
